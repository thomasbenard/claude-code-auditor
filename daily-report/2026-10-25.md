# Claude Code Daily Report — October 25, 2026

## Highlights

Anthropic open-sourced the OS-level sandbox behind Claude Code (`sandbox-runtime`) on October 24 under Apache-2.0. The community also digested v2.1.309 and v2.1.310, which together fixed a long list of sandbox, deny-rule and hook bypasses.

## Official Announcements

**[sandbox-runtime (srt) open-sourced](https://aiweekly.co/alerts/anthropic-open-sources-claude-code-sandbox-under-apache-20)** — On October 24, Anthropic released `@anthropic-ai/sandbox-runtime` (Apache-2.0, research preview). It uses Seatbelt on macOS, bubblewrap on Linux, and an alpha Windows build, with network allowlists, credential masking, and the ability to sandbox MCP servers by swapping `npx` for `srt`. Reported by AI Weekly; the original Anthropic source was not checked.
