## Official Announcements

**[Claude Code v2.1.316](https://github.com/anthropics/claude-code/releases)** — Released October 31. Fast mode for Opus 4.8 is deprecated as of October 30 and removed November 30, after which it returns an error instead of falling back; the changelog recommends migrating to Opus 5.5. Also adds `CLAUDE_CODE_DISABLE_ULTRATHINK` (turns off the ultrathink keyword), `CLAUDE_CODE_SUBAGENT_EFFORT` (default effort for subagents), and fixes for the Bash tool, PowerShell hooks, and Grep/Glob on Windows.

**[Claude Code v2.1.314](https://code.claude.com/docs/en/changelog)** — Released October 30. Adds `permissions.blockWritesOutsideWorkingDirectories`, which makes Write, Edit, and NotebookEdit refuse paths outside the working directories in every permission mode. `claude -p` now exits with code 1 when startup fails, `/ultrareview` checks workspace trust before running git, and an "Invalid effort level" failure when an admin caps effort is fixed.
