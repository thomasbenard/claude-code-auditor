# Claude Code Daily Report — October 15, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Two Claude Code releases shipped on October 14 (v2.1.299 and v2.1.300), the first adding idle compaction of long conversations before the prompt cache expires. Elsewhere it was a fairly quiet day: a security write-up on the Claude Code Desktop preview pane and a handful of small community tools on Hacker News.

## Official Announcements

**[Claude Code v2.1.299](https://github.com/anthropics/claude-code/releases)** — Conversations over 200K tokens that stay idle about 54 minutes are now compacted before the one-hour cache expires (disable with `"idleCompaction": false`). Also adds `CLAUDE_CODE_DISABLE_FILE_MENTIONS`, `/effort` and `/fast` in agent view, and a fix for `/usage` showing more than 100%.

**[Claude Code v2.1.300](https://github.com/anthropics/claude-code/releases)** — Mods get `virtualText` and a `prompt.change` hook, OpenTelemetry gains cache-creation token attributes, and `/advisor` is available on Claude Platform on AWS. Behavior changes: background commands still running 1.5 s after exit are force-killed, and `--sandbox`/`--no-sandbox` are removed from `claude remote-control`.

## Articles & Blog Posts

**[Claude Code Desktop Vulnerability: Preview Pane Data Exfiltration](https://noma.security/noma-labs/sneakpeek-how-the-preview-pane-in-claude-code-desktop-can-exfiltrate-your-data)** by *Noma Labs* — A malicious HTML file (e.g. a fake coverage report) could run JavaScript in the preview pane and exfiltrate local files such as SSH keys.
