## Tools & Releases

**[Claude Code v2.1.295](https://github.com/anthropics/claude-code/releases)** — Published October 8. Command and HTTP hooks accept `onFailure: "block"`, so an action is blocked if its hook cannot start, times out, or exits unexpectedly. Also adds Program Status Protocol (OSC 7501) support so terminals can show working/waiting/done, a `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS` cap for unattended retries on 429/529 errors, and new Claude apps gateway options (`timeouts.upstream_ttfb_ms`, per-upstream `models`, `request-id` header). Fixes `[1m]` model sessions failing when a gateway or cloud provider refuses the context-1m beta, `claude -p` dropping earlier responses, and remote MCP servers staying disconnected instead of reconnecting with backoff.

**[Claude Code v2.1.294](https://github.com/anthropics/claude-code/releases)** — Published October 8. `prompt` and `agent` hooks written as instructions (e.g. "Block commands that...") now actually block, and Stop/SubagentStop `prompt` hooks are judged more accurately so Claude is less likely to stop early.
