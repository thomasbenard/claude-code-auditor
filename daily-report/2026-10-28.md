## Official Announcements

**[Claude Code v2.1.312](https://github.com/anthropics/claude-code/releases)** — Released October 27. Fixes Claude overwriting very large CLAUDE.md, rules, or @-included files after reading only their start, and fixes per-directory and `paths:` skills not being found after a Bash `cd` into a deeper git repo. Adds click-to-send for queued messages in fullscreen, an effort level in the model picker for cloud routines, and renames the "session limit" message to "5-hour limit". Prompt and agent hooks are now capped at 24 concurrent per session. Full notes in the [official changelog](https://code.claude.com/docs/en/changelog).

**[Manage costs and demonstrate ROI for Claude Code on Google Cloud](https://claude.com/resources/articles/how-to-manage-costs-and-demonstrate-roi-for-claude-code-on-google-cloud)** — New Anthropic article (October 27) aimed at teams running Claude Code through Google Cloud, covering cost control and how to show return on investment.

**[Claude Code v2.1.311](https://github.com/anthropics/claude-code/releases)** — Released October 26 (just outside the 24-hour window, but its details were not covered in earlier reports). Notable fixes: sessions no longer stop with "Usage credits required for 1M context" past 200K tokens (they compact and continue), subagents can use MCP tools from servers that connect late, and `SubagentStop` hooks fire once instead of repeatedly. `ultrathink` now runs at xhigh effort on several models.
