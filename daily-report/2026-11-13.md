## Official Announcements

**[Claude Code v2.1.323](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)** — Released November 12. Adds Code Mode (experimental, opt-in), where Claude writes JavaScript to call its tools ([docs](https://code.claude.com/docs/en/code-mode)). Plugins can declare `engines["claude-code"]` in `plugin.json` so out-of-range versions are not installed or loaded, and `claude plugin validate` now type-checks a plugin's TypeScript hooks module (`--strict` fails on warnings). Security fix: `--permission-mode auto` / `defaultMode: auto` now falls back to Manual mode when auto mode is unavailable, instead of a more permissive mode. Long-running hooks in `claude -p` and SDK sessions now emit a progress heartbeat every 30 seconds.
