## Official Announcements

**[Claude Code v2.1.310](https://github.com/anthropics/claude-code/releases)** (Oct 23) — Adds the Monitor tool and plugin monitors on Bedrock, Vertex, and Foundry, retries requests behind gateways that reject some beta values, and lets Enterprise custom roles control access to cloud sessions and Remote Control.

**[Claude Code v2.1.309](https://github.com/anthropics/claude-code/releases)** (Oct 22) — Sandbox hardening on macOS and Linux (shell startup files no longer run outside the sandbox), many Bash permission-check fixes, and `claude ultrareview` now requires workspace trust (`--trust-workspace` for scripts). `sed -i` is now treated as a standard Bash command and is no longer restored by `/rewind`.
