# Claude Code Daily Report — August 10, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Anthropic announced that new Claude Code sessions on Pro, Max, and Team plans will default to **auto mode** starting August 14, 2026, replacing step-by-step human approval with autonomous execution unless an action is deemed irreversible, destructive, or reaches outside the user's environment. Internal testing across 1,053 paid users found auto mode caught 89% of dangerous commands versus just 13.6% for manual human review — attributed to "approval fatigue," since users reflexively approve 97% of all prompts. Third-party testing by Trajectory Labs found auto mode blocked all 72 attempted prompt-injection attacks in its test set. Pinned and managed permission defaults are unaffected; enterprise and API users get the change in September or later. Separately, Claude Code shipped v2.1.225 and v2.1.226 (August 8) with gateway spend-limit warnings, a workspace trust prompt for untrusted directories, and fixes for a transient OAuth 401 error and intermittent macOS MCP keychain-read failures.
