# Claude Code Daily Report — September 18, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Yesterday was dominated by one big product move: Anthropic redesigned **Claude Code Projects** so a single conversation can now split work across parallel cloud agent threads coordinated by Claude itself, with shared memory and a common file library. Alongside that, the routine **v2.1.275** changelog shipped the same day with account/gateway sign-in improvements and a new "send-now" key. Coverage was largely enthusiastic but included some skepticism about usage-cost implications of running multiple parallel agents at once.

## Official Announcements

**[Claude Code Projects redesign — parallel agent threads](https://claude.com/blog-category/announcements)** — Anthropic rolled out a beta redesign of Projects: each project now has a coordinator that receives instructions and directs parallel worker threads, which run as independent cloud sessions that can open pull requests and run tests on their own. The coordinator monitors progress, resolves overlapping edits as merge conflicts, and assembles the final result; threads share memory and a common library of uploaded files and artifacts. Beta access started September 17 for a subset of Pro/Max subscribers using cloud sessions with no existing web/desktop projects, expanding over the following week, with Team/Enterprise access to follow.

**[Claude Code changelog — v2.1.275](https://code.claude.com/docs/en/changelog)** — Released September 17 with 30+ fixes. Notable additions: signed-in account confirmation on Claude apps gateway sign-in, a new send-now key (`ctrl+enter` or `ctrl+x ctrl+s`) to interrupt the current turn and send queued messages, a startup warning when a configured `otelHeadersHelper` fails, syncing of claude.ai-enabled skills/plugins into terminal sessions (opt out via `syncClaudeAiSkills: false` / `syncClaudeAiPlugins: false`), and `/plugin install <plugin> --marketplace <source>`. Fixes include a prompt-cache-breaking bug where a restored memory file's age note changed between requests, `--forward-subagent-text` dropping messages from `context: fork` skill subagents, and several VSCode and web session-handling issues.
