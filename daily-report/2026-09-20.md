## Official Announcements

**[Claude Code v2.1.278](https://github.com/anthropics/claude-code/releases)** — Auto mode for Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateway users now defaults to a server-side classifier that isn't billed for classifier overhead; `CLAUDE_CODE_AUTO_MODE_SERVER=0` opts out, and `/status` gained an "Auto mode server" row.

**[Claude Code v2.1.277 — AGENTS.md support](https://x.com/trq212/status/2101009392611278961)** — Starting in 2.1.277, Claude Code reads `AGENTS.md` when a folder has no `CLAUDE.md`, toggleable in `/config`. It closes the single highest-voted open issue in the repo (5,200+ reactions since August 2025) and ships alongside a new "Claude Code mods" mechanism, with AGENTS.md as the first built-in mod.
