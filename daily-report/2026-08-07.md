# Claude Code Daily Report — August 7, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Claude Code v2.1.223 shipped August 6 with 19 CLI changes, most notably four security fixes closing permission-bypass gaps (hidden Bash command segments, Unicode-padded approval prompts, workflow sandbox escapes via dynamic `import()`, and an org bypass-permissions policy gap) plus `owner/*` wildcard marketplace restrictions. The release drew a same-day community regression checklist and at least one bug report about native tool behavior.

## Official Announcements

**[Claude Code v2.1.223 release](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)** — Adds `owner/*` wildcard entries to `strictKnownMarketplaces`/`blockedMarketplaces` for org-wide marketplace policies; adds a warning when a workflow agent, forked skill, slash command, or resumed background agent requests a restricted subagent model and falls back to the parent model; adds a `/teleport` hint in cloud sessions for continuing a session locally; fixes a Bash permission-check bypass where a crafted command could hide part of itself from approval; fixes tab/invisible-Unicode padding hiding command content in the approval dialog; fixes workflow scripts using dynamic `import()` to escape the workflow sandbox; fixes an agent-definition `bypassPermissions` mode ignoring the org's bypass-permissions-disable policy.
