# Claude Code Daily Report — July 3, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Anthropic shipped two releases in two days: v2.1.198 (July 1) made background subagents the default and brought Claude in Chrome to general availability, while v2.1.199 (July 2) fixed a long tail of background-agent reliability bugs and let stacked slash-skill invocations load up to five skills at once. Separately, the steganographic-request-marking story kept spreading through security and tech press — Anthropic is reportedly removing the covert Chinese-proxy-detection code that a Reddit user surfaced on June 30.

## Official Announcements

**[v2.1.198 — Subagents run in the background by default](https://code.claude.com/docs/en/changelog)** — Claude now keeps working while subagents run and gets notified when they finish, a behavior that had been in gradual rollout. The same release brings Claude in Chrome to general availability, adds a `/dataviz` skill for chart and dashboard design, and makes background agents launched from `claude agents` commit, push, and open a draft PR automatically instead of stopping to ask.

**[v2.1.199 — Skill stacking and background-agent reliability fixes](https://code.claude.com/docs/en/changelog)** — Stacked slash-skill invocations (`/skill-a /skill-b do XYZ`) now load all leading skills instead of just the first. The release also fixes silent subagent failures after rate limits or server errors, a Linux background-agent daemon crash loop, and SSL errors that previously burned retries before showing an actionable fix.

## Community Discussions

**[Anthropic is removing its covert code for catching Chinese competitors](https://www.theregister.com/ai-and-ml/2026/07/01/anthropic-is-removing-its-covert-code-for-catching-chinese-competitors/)** — Following a June 30 Reddit disclosure (u/LegitMichel777) that Claude Code embeds hidden, steganographically-encoded markers — invisible Unicode substitutions and date-format switches — to flag users on Chinese timezones or proxying through known Chinese AI labs (DeepSeek, Moonshot, MiniMax, Zhipu, and others), Anthropic is reportedly pulling the mechanism. The story spread widely on [Hacker News](https://news.ycombinator.com/item?id=48734373) and in follow-on coverage (e.g. [cybersecuritynews.com](https://cybersecuritynews.com/anthropic-claude-hidden-code/)), with debate centered on whether undisclosed anti-distillation detection is a reasonable defense against API resellers or an unacceptable transparency lapse.
