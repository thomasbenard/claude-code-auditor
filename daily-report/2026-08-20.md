## Official Announcements

**[Claude Code changelog — v2.1.236](https://code.claude.com/docs/en/changelog)** — Adds the `ANTHROPIC_DEFAULT_MODEL` env var (sets the model new sessions start on, overridable and persisted via `/model`), `notify_when_idle` for cross-session `SendMessage` (opt-in, one-shot idle notice between local sessions), and macOS sandbox hardening where wildcard read-deny rules (e.g. `**/.env`) now take precedence and can't be bypassed by renaming.
