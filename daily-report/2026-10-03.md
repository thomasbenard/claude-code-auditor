# Claude Code Daily Report — October 3, 2026

## Highlights

A calm day after the mods launch: Claude Code **v2.1.288** shipped on October 2 with a built-in "You should know" mod and a `--max-findings` option for `/code-review`. The community reacted to mods with a first wave of Show HN projects (UI explainers, multi-harness delegation, Chrome browsing), and no new official blog post was published.

## Tools & Releases

**[Claude Code v2.1.288](https://github.com/anthropics/claude-code/releases)** (Oct 2) — Adds the first-party "You should know" mod (enable with `/plugin enable cc-plugin-you-should-know@builtin`; requires telemetry), `--max-findings <n>|all` for `/code-review` (the choice persists until `--max-findings default`), Ctrl+F session search, recovery of prompts cleared with Ctrl+C (press Up), a re-authentication prompt when an MCP server requests extra OAuth scope, and fixes for mid-response API timeouts and auto-compaction.

**[What's Agent Doing](https://github.com/tzafrir/whats-agent-doing)** — Show HN: a Claude Code UI mod that explains each step the agent takes.

**[Multi-harness delegation mod](https://github.com/franciscocarloserra/claude-code-multiharness-delegation)** — A mod that lets Claude Code delegate work to other agent harnesses.

**[pi-delegate](https://github.com/randomm/pi-delegate)** — Show HN: delegates Claude Code's work to pi and a cheaper model to cut costs.

**[Agent-Chrome](https://github.com/rav4nn/agent-chrome)** — Show HN: lets Claude Code browse in Chrome without stealing window focus.

**[Television](https://television.run/)** — Show HN: an open source GUI for agent harnesses, presented as a place for all of an agent's artifacts (multiple harnesses supported, Claude Code among them).
