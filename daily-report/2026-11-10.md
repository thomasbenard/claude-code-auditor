# Claude Code Daily Report — November 10, 2026

## Highlights

November 9 brought **Claude Fable 5.2**, now the default Fable model in Claude Code through **v2.1.321**, a release that also tightens permission and sandbox handling (74 fixes). Anthropic's blog also published a model-choice guide and a JPMorganChase customer story.

## Official Announcements

**[Claude Code v2.1.321](https://code.claude.com/docs/en/changelog)** (November 9) — Main additions:

- Claude Fable 5.2 (`claude-fable-5-2`) is the new default Fable model: 1M context, $8/$40 per Mtok, $0.20/Mtok cache reads.
- `--settings <file>` for `claude remote-control`: the file applies to every session it starts.
- VS Code: a warning appears when both an auth token and an API key are set.

**Behavior changes in v2.1.321** — Saved Fable 5.1 picks move to `fable` (use `/model claude-fable-5-1` to switch back). Mods no longer turn on without asking in auto and bypass modes, and no longer load in `dontAsk` mode. A mod's own tool calls (`$.tool.call`, `$.mcp.call`) raise no prompt, but deny rules and organization policy still apply. On Windows, programs Claude Code starts itself (such as git) skip relative and UNC PATH entries. Remote Control sessions keep the folder they were started in.

**Notable fixes in v2.1.321** — MCP OAuth no longer sends secrets such as refresh tokens to another host after a redirect. A read-only Bash command no longer runs outside the sandbox without a prompt. NotebookEdit and Edit no longer damage the first cell or first match on network paths. Fast mode now retries standard speed on the same model first instead of stalling.
