## Official Announcements

**[Claude Code adds AGENTS.md fallback support](https://x.com/trq212/status/2101009392611278961)** — Starting in v2.1.277, if a folder has no `CLAUDE.md`, Claude Code now falls back to reading `AGENTS.md` (OpenAI's shared instructions format used by Codex, Cursor, Aider, Copilot, and others). Toggleable via `/config`; `CLAUDE.md` still takes priority when both exist. Not yet available on Bedrock, Vertex AI, or Foundry.
