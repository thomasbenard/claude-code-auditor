## Tools & Releases

**[Claude Code v2.1.307](https://github.com/anthropics/claude-code/releases/tag/v2.1.307)** (Oct 21)
- Added the `claude_code.safety_event` OpenTelemetry event, emitted when a permission rule, auto mode, a safety check, a hook or the sandbox stops, prompts on, or sends back a tool call.
- Added `/claude-api api-version` to move Claude API code to version `2026-10-21`, and `@claude review stop` (also `off`, `pause`) to end an `@claude review always` subscription in Code Review.
- Fixed HTTP MCP tool calls being sent twice when a connection closed mid-call; only read-only or idempotent tools are now retried.
- **Watch out:** self-hosted runner checkout hooks now time out after 30 minutes by default (`--checkout-hook-timeout-min`, `0` to disable). `axScreenReader` / `CLAUDE_AX_SCREEN_READER` in settings `env` blocks now only apply from user, managed or `--settings` sources.

**[Claude Code v2.1.306](https://github.com/anthropics/claude-code/releases/tag/v2.1.306)** (Oct 21) — Fixes `claude -p` in cloud sessions reporting "Not logged in", and API errors being replaced by a misleading "prompt is too long" (plus unnecessary compaction) in sessions with many MCP tools.

**[Claude Code v2.1.308](https://github.com/anthropics/claude-code/releases/tag/v2.1.308)** (Oct 22) — Bug fixes and reliability improvements only.
