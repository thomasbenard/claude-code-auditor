## Tools & Releases

**[Claude Code v2.1.292](https://github.com/anthropics/claude-code/releases/tag/v2.1.292)** — Release published October 6 with 100+ fixes and improvements. New: `claude plugin install --marketplace <source>`, an effort parameter for sub-agents, prompt caching for mods (`$.model.complete` with `cache: true`), a `prompt.autocomplete` mod event, and workflow agents in the `agent.spawn` hook. `claude -p` and SDK sessions now start faster because the first turn no longer waits for HTTP/SSE MCP servers, and MCP protocol negotiation defaults to version 2026-07-28.

Notable security fixes: PreToolUse hook approvals no longer bypass permission prompts for network (UNC) path file reads, sandboxed commands can no longer access `/ultrareview` uploads improperly, and a tampered server-managed settings cache can no longer disable the built-in policy plugin. Other fixes cover `/loop` stopping after a restart in background sessions, plan mode restoration with `/resume`, and @-mentioned text files over 256KB being silently omitted.
