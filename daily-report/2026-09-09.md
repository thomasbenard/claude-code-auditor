# Claude Code Daily Report — September 9, 2026

## Highlights

Two Claude Code releases shipped September 8: v2.1.265 brought plugin-dir hot-reloading, a 1GB tool-result disk cap, and telemetry additions, followed hours later by a v2.1.266 hotfix for a gateway-auth regression it introduced. Otherwise a quiet news day — no major community or ecosystem stories surfaced beyond the release cycle.

## Official Announcements

**[Claude Code v2.1.265](https://github.com/anthropics/claude-code/releases)** — Added `--plugin-dir` support for loading a folder of plugins with hot-reloading, a 1GB cap on tool results saved to disk (with truncation indication), and `user.email`/`user.groups` telemetry from Claude Desktop and Cowork. Also fixed prompt-cache reuse, syntax highlighting, session resumption, and plugin path validation issues.

**[Claude Code v2.1.266](https://github.com/anthropics/claude-code/releases)** — Same-day hotfix: the undocumented `CLAUDE_CODE_USE_GATEWAY` env var started forcing Cloud-gateway sign-in on its own in 2.1.265, breaking setups that combine it with an API key, `apiKeyHelper`, or custom auth headers. Reverted to its original opt-in-only behavior.
