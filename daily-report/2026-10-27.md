# Claude Code Daily Report — October 27, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

Claude Code v2.1.311 was published on October 26, mostly bug fixes (long sessions that no longer stop at 200K tokens, subagents that can use late-connecting MCP servers) plus a faster startup. On the community side, a Tell HN reports that Claude Code can now flag bugs in its own behavior and offer to send them to Anthropic. A dev.to post also reports that Anthropic donated the Agent Skills standard to a vendor-neutral foundation, but it cites no primary source.

## Official Announcements

**[Claude Code v2.1.311](https://github.com/anthropics/claude-code/releases/tag/v2.1.311)** (published October 26) — Mostly fixes. Sessions no longer stop with "Usage credits required for 1M context" when a request exceeds 200K tokens (Claude Code compacts and continues), subagents can use MCP tools from servers that connected after they started, and `SubagentStop` hooks no longer fire about twice a minute per subagent. `ultrathink` now runs at xhigh effort on Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable 5.1 through Anthropic's API, `self-hosted-runner` gains `--hold-idle-file` and `--max-hold-min`, and startup is faster for Pro and Max accounts. Also fixed: freezes caused by very long CLAUDE.md list items, and stale MEMORY.md / CLAUDE.md content after compaction.
