## Official Announcements

**[Claude Code v2.1.318](https://code.claude.com/docs/en/changelog)** (November 4) — Main changes:

- `claude auth status` now shows `loginExpiresAt`, and `claude -p` JSON results include `credential_expires_at`, so a script can tell when the stored claude.ai sign-in ends. `claude -p` in text mode prints a warning on stderr starting 10 days before that date.
- Claude Code no longer installs or updates the IDE extension when started in an IDE terminal. Use `/ide` from a terminal outside the IDE instead.
- Background subagents now move a shell command to the background after 3 minutes on all providers.
- `deniedMcpServers` URL entries now also block matching Anthropic-provided servers.
- Cloud sessions on Anthropic-hosted environments get a "No repository" option.
- `/claude-api managed-agents-onboard` now defaults new agents to the `auto` permission policy.
- `--continue` no longer loses the earlier conversation after malformed tool call retries (a regression introduced in v2.1.314). The release lists 47 bug fixes in total.
