## Tools & Releases

**Added**
- `/auto-mode-setup`: guided setup that teaches auto mode about your environment, also available on Bedrock, Vertex, Foundry, Claude apps gateway and telemetry-disabled sessions.
- `/claude-api managed-agents-secure`: compares a Managed Agents agent's settings with Anthropic's security guide, without changing anything.
- Mods: `decider: "person"` option for a `tool.check` answer, `e.isReadOnly` on the `tool.check` event, and a transcript line when a plugin that runs first skips one of your mod's hooks.
- Tool names from earlier in the session are kept in the compaction summary (Ctrl+O).
- Warning on Pro and Max plans when resuming an inactive conversation would use a large share of the 5-hour limit.

**Fixed (selection)**
- `rm -r` on mounted drives or top-level folders (`/Volumes`, `/media`, `/mnt/c`) now gets the safety prompt.
- `claude --worktree` no longer removes a worktree and its branch at exit without asking, which could lose commits.
- Plugins no longer keep headless runs going past `--max-turns`, Stop, or ended input.
- Sandboxed commands on Linux no longer fail when `sandbox.filesystem.denyRead` globs contain brackets.
- `CLAUDE_CODE_TRANSCRIPT_LOCAL_GC` no longer drops messages when the disk fills up.
- `context_management: Extra inputs are not permitted` errors behind LLM gateways (Claude Code now resends without that field).
- Subagents no longer sometimes forget their latest work when messaged or resumed right after finishing.

**Improved / Changed**
- `/usage` states when a rate limit ends; faster resume of large compacted sessions in SDK/headless mode; better responsiveness with many concurrent subagents; smaller session files in auto mode.
- Tool search is on by default behind a custom `ANTHROPIC_BASE_URL` (with a retry on 400/422).
- Compaction resends the skill list; `/reload-skills` sends only new or changed skills. Skills from one source can register at most 1,024 hooks per session.
- Cloud sessions no longer wait for local stdio MCP servers of synced plugins unless `alwaysLoad: true` is set.

**VS Code**
- Mod drawing in the chat panel for Bedrock, Vertex, Foundry, gateway and telemetry-off sessions.
- SessionStart command hook time no longer counts toward the 60-second "Subprocess initialization" limit (up to 10 minutes total).
- Past conversations no longer hide sessions when `claudeCode.claudeProcessWrapper` is set.
