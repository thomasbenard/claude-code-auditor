# Claude Code Daily Report — November 3, 2026

> Trending articles, discussions, and resources about Claude Code from the previous day.

## Highlights

No new item was published on November 2. The only change in the official changelog is the **v2.1.317** release, dated November 3, which adds a confirmation before a tool call sends your account email address to the network, a fail-closed option for Agent SDK hook callbacks, and a new cost report for the Claude apps gateway.

## Official Announcements

**[Claude Code v2.1.317](https://code.claude.com/docs/en/changelog)** (November 3) — Main additions:

- A check asks before a web or shell tool call sends your account email address to the network.
- `onFailure: "block"` for Agent SDK hook callbacks: a callback that fails now blocks the action instead of letting it run.
- A warning in `/schedule` when a new cloud scheduled task gets connectors you did not ask for, with how to remove them.
- `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`: set to `1` on a self-hosted runner so that `claude -p` run inside a session uses that session's ID and transcript, as in earlier versions.
- A cost report on the Claude apps gateway admin API (`GET /v1/organizations/analytics/cost`), grouped in total, per developer, per day or per IdP group.
- `anthropic.plan`, `anthropic.seat_type`, `anthropic.provider` and `anthropic.custom_base_url` added to OTel metrics, events and spans.

**Behavior changes in v2.1.317** — Subagents and teammates on a different model from the main conversation now use that model's saved effort level or its default, instead of the session's. The Read tool's "file unchanged since your last Read" stub is removed: reading an unchanged file again returns its content.

**Notable fixes in v2.1.317** — `claude -p` now exits 1 (instead of 0) when a full disk or quota loses its transcript. Partial Grep and Glob results are no longer treated as complete when a search hits its time limit. On Windows, every tool call is no longer refused on volumes where the native path lookup fails.
